## About The Project

**AI Learning Companion** is an intelligent agent that helps students decide their next learning steps based on their current progress. Built as part of an assignment for **SkillWiz**, this project demonstrates the power of AI agents, tool usage, memory handling, and database integration.

### What It Does

- **Fetches your learning progress** from a database
- **Understands your current stage** (completed topics, pending topics, streak)
- **Suggests meaningful next steps** based on your actual progress
- **Remembers conversations** for context-aware responses
- **Works immediately** - No API key required!
